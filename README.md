# PetBar

Windower 4 companion HUD for FFXI. This repository is being initialized for independent PetBar development.

**Status:** PetBar SMN Test 1 is experimental and has not yet been tested in-game. The working code and cumulative testing history will live on the `dev/smn-test1-2026-11-04` branch. `main` remains documentation-only until a known-good in-game build is accepted.

See the development branch's README.md, WORKFLOW.md, and TESTING.md before installation.
